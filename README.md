# סוכן מנכ״ל

מסך אחד שמראה את כל הסוכנים בעסק: מה רץ לבד, מה רץ במחשב ומה בענן, מה נתקע, ואיפה כל סוכן נבנה. כשמשהו לא עובד, מגיעה הודעה בוואטסאפ.

הכול רץ על המחשב שלך. הנתונים שלך לא עולים לשום מקום.

## התקנה

פותחים את Claude Code וכותבים:

> תתקין לי את סוכן מנכ״ל מ-https://github.com/talbs1988-dotcom/ceo-agent

Claude ישאל כמה שאלות ויפתח את הדשבורד.

**לעדכון לגרסה חדשה:** כותבים שוב את אותו משפט. Claude יעדכן, וכל מה שהגדרתם יישמר.

## אחרי ההתקנה

כותבים ל-Claude:

- **"סוכן מנכ״ל, תסרוק"** כדי לעדכן את הדשבורד
- **"מה נתקע?"** כדי לקבל תשובה קצרה
- **"תפעיל התראות"** כדי לקבל הודעה בוואטסאפ כשסוכן נתקע
- **"תחבר לעוזר האישי"** כדי לשאול את המנכ״ל גם מהוואטסאפ
